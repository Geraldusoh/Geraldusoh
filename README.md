## Selected project experience

### BookMe Self-Scheduler — Tritek project programme

**Role: Business Analyst, Project Insight team**

Contributed to analysis for a proposed no-code consultation booking solution. The project explored self-service scheduling, calendar synchronisation, time-zone handling and automated reminders to address manual booking coordination.

The team’s business case compared alternative approaches and considered requirements, expected benefits, integration risks and adoption. Benefits described in the project were forecasts, rather than verified operational results.

### Project Lux — Tritek project programme

**Role: Business Analyst, project team**

Participated in requirements discovery for the Luxemporium marketplace, including a team review of sponsor elicitation questions. Team documentation covered functional and non-functional requirements, stakeholder analysis and versioned requirements review across customer registration, product discovery, checkout and order handling.

These were collaborative programme projects. My portfolio distinguishes my contribution from team deliverables.
